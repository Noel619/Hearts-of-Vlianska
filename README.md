# Sombras de Vlianska

RPG de escuadra y supervivencia en mundo abierto, en 3D, ambientado en el metro de Vlianska.

> En construcción. Este repositorio contenía antes *Hearts of Vlianska* (gran estrategia en 2D); el juego nuevo parte de la misma historia.

La historia completa del universo (crónica, facciones, líderes, estaciones, túneles, sucesos y tecnología) está en [`docs/historia/`](docs/historia/).

## Ejecutarlo

```bash
npm install
npm run dev
```
